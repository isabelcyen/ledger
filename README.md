# 💰 個人記帳（GitHub Pages ＋ Google 試算表）

手機優先的個人記帳網頁。程式放在 GitHub Pages（免費、https），資料存在**你自己 Google 雲端硬碟裡的試算表**，可在 iPhone／Android「加到主畫面」當 App 使用，不必上架 App Store。

## 功能

| 分頁 | 內容 |
|---|---|
| **支出** | 日期、時間、類別（＋ 隨時新增）、項目 🎤、價格 🎤、幣別、備註；「🎤 一句話記帳」：說「午餐 牛肉麵 一百五十元」自動填好類別／項目／價格 |
| **收入** | 同上，欄位為「金額」 |
| **統計** | 日／週／月／年／自訂區間；收入、支出、結餘、日均支出；收支趨勢圖；支出／收入類別佔比；依原幣別小計；明細（點一下可編輯）。手機可左右滑動切換期間 |
| **匯出/入** | 依區間匯出 CSV（Excel 可開）或 JSON；**附加匯入**（相同 ID 自動略過，不會覆蓋或刪除）；開啟 Google 試算表連結 |

其他：多幣別（設定匯率後統計自動換算成台幣，可一鍵線上更新匯率）、離線時先記在手機、恢復網路自動同步、深色模式。

> 備份與還原請直接用 Google 試算表的「檔案 → 版本記錄」；要整份下載用「檔案 → 下載 → Microsoft Excel」。

---

## 架構

```
iPhone / 瀏覽器 ──(https POST + Token)──▶ Google Apps Script 網頁應用程式 ──▶ 你的 Google 試算表
     ▲
GitHub Pages（index.html、app.js…，純靜態檔案）
```

- 網頁本身沒有任何密碼或資料；**Token 只存在你手機瀏覽器裡**，不會進 GitHub。
- Apps Script 以「你本人」身分執行，所以試算表不需要分享給任何人。

## 安裝步驟（約 10 分鐘）

### 1. 建立 Google 試算表與後端

1. 開 [Google 雲端硬碟](https://drive.google.com) → 新增 → Google 試算表，命名例如「個人記帳」。
2. 試算表選單：**擴充功能 → Apps Script**。
3. 刪掉編輯器裡原本的內容，把本專案 `apps-script/Code.gs` 全部貼上，按 💾 儲存。
4. 上方函式下拉選 **`setup`** → 按「執行」。
   - 第一次會要求授權：選你的 Google 帳號 → 出現「Google 尚未驗證這個應用程式」→ **進階 → 前往（不安全）** → 允許。（這是你自己寫的腳本，只存取你自己的試算表。）
5. 下方「執行紀錄」會印出 **API Token**，先複製起來。試算表會自動建立「支出、收入、類別、設定」四個工作表。
6. 右上 **部署 → 新增部署作業** → 齒輪選「**網頁應用程式**」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**（沒有 Token 的請求一律拒絕）
   - 按「部署」，複製 **網頁應用程式網址**（結尾是 `/exec`）。

### 2. 把網頁放到 GitHub Pages

1. GitHub 新增 repository（例如 `ledger`，Public 即可）。
2. 把本專案**除了 `apps-script/` 以外**的檔案上傳到根目錄（`index.html` 要在最外層）。`apps-script/` 一起上傳也沒關係，裡面沒有任何機密。
3. Repository → **Settings → Pages** → Source：`Deploy from a branch`，Branch：`main`、資料夾 `/ (root)` → Save。
4. 約 1 分鐘後網址為 `https://你的帳號.github.io/ledger/`。

### 3. iPhone 安裝與設定（順序很重要）

1. 用 **Safari** 開上面的網址 → 分享按鈕 → **加入主畫面**。
2. **從主畫面的圖示打開**，再按右上 ⚙️：選「Google 試算表」→ 貼上 `/exec` 網址與 Token → 測試連線 → 儲存設定。

> ⚠️ iPhone 的主畫面 App 與 Safari 的儲存空間是分開的，所以**要在主畫面開啟的那個 App 裡設定**；在 Safari 設定過的，主畫面版本看不到。

Android：用 Chrome 開網址 → 選單 → 「加到主畫面／安裝應用程式」，一樣在開啟後設定。

## 語音輸入說明

- 使用瀏覽器內建的 Web Speech API，需 **https** 與**麥克風權限**；辨識由 Apple／Google 的語音服務處理，需要網路。
- 價格欄會自動把中文數字轉成數字：「一百二」→120、「兩萬三」→23000、「十二塊五」→12.5、「美金三十」→30 並切換幣別為 USD。
- **iPhone 若按 🎤 沒反應或跳錯誤**（部分 iOS 版本在「主畫面模式」不支援網頁語音辨識），按 🎤 失敗後游標會自動停在欄位上，直接點**鍵盤右下角的麥克風（聽寫）**說話即可，效果相同。
- 設定裡可切換辨識語言（中文台灣／英文／日文）。

## 匯入 CSV 格式

```
類型,日期,時間,類別,項目,金額,幣別,備註,ID
支出,2026-11-26,12:30,午餐,牛肉麵,150,TWD,,
收入,2026/11/25,09:00,薪資,11 月薪資,50000,TWD,公司轉帳,
```

- 類型：`支出`／`收入`；日期可用 `-` 或 `/`；ID 可留空（會自動產生）。
- 沒有「類型」欄時，負數金額視為支出。
- 「匯出/入」頁可下載範本。

## 在試算表直接編輯

可以直接在試算表改資料或新增列（ID 留空，下次讀取時會自動補上）。日期請用 `2026-11-26` 格式，時間 `12:30`。網頁會在每次打開或按右上狀態鈕時重新讀取。

## 更新程式

- **網頁**：直接覆蓋 GitHub 上的檔案即可；若手機沒更新到，把 `sw.js` 裡的 `ledger-v1` 改成 `ledger-v2` 再上傳。
- **Apps Script**：貼上新程式後，**部署 → 管理部署作業 → ✏️ 編輯 → 版本：新版本 → 部署**（網址不變）。只按儲存不會生效。

## 安全

- Token 外流時：Apps Script 執行 `resetToken`，再到網頁設定貼上新 Token。忘記 Token 執行 `showToken`。
- 所有寫入都有鎖定（LockService），多裝置同時記帳不會互相覆蓋。
- 以 `= + - @` 開頭的文字會加上 `'` 前綴，避免被試算表當作公式執行。
